# Security Operations
Third-party penetration tests are performed annually by an independent firm.
Critical vulnerabilities are patched within 7 days and high vulnerabilities within 30 days.
Production systems are hosted in AWS in the us-east-1 region.
Database backups are taken daily and retained for 35 days.
Backup restoration is tested every quarter.
Logs from production systems are retained for one year.
We use endpoint detection and response (EDR) software on all company laptops.
All code changes require peer review before merging.
