# Access Control

All employees must use multi-factor authentication (MFA) for access to production systems. Access reviews are performed quarterly by the security lead.

# Encryption

Customer data is encrypted at rest using AES-256 and in transit using TLS 1.2 or higher.

# Incident Response

Security incidents are triaged within 24 hours. A post-incident review is completed within 5 business days.

# Backups

Database backups run daily and are retained for 35 days. Restore tests are performed twice per year.

# Vendor Management

New vendors that process customer data undergo a security review before onboarding.
