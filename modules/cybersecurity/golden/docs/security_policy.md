# Access Control

Multi-factor authentication (MFA) is required for all production systems and administrative consoles. User access reviews are performed quarterly by the security lead. Access is revoked within 24 hours of an employee's termination.

# Encryption

Customer data is encrypted at rest using AES-256 and in transit using TLS 1.2 or higher. Company laptops use full-disk encryption and lock automatically after 10 minutes of inactivity.

# Backups and Recovery

Database backups run daily and are retained for 35 days. Restore tests are performed twice per year.

# Incident Response

Security incidents are triaged within 24 hours. A post-incident review is completed within 5 business days.

# Vulnerability Management

Vulnerability scans run weekly. Critical vulnerabilities are patched within 14 days. Penetration testing is performed annually by an independent third party.

# Logging

Audit logs are centralized and retained for 12 months.

# Passwords

Passwords must be at least 12 characters long and employees must use the company password manager.
